# ⚡ ARC PROTOCOL — Протокол Дуги

**Тактический Grid-Roguelite Deckbuilder** (*Into the Breach* × *Slay the Spire* × *Balatro*), созданный для первого этапа отбора в RND-команду **GamesUp42**.

## О чём игра и в чём её фишка

Вы управляете автономным энерго-ядром на тактической арене **5×5**. Все атаки врагов заранее телеграфируются красными зонами на сетке. Вместо обычного обмена ударами вы строите пространственные комбинации:

1. **Дуговые Цепи (Arc Chain):** устанавливайте **Энерго-Реле**, **Катушки Теслы** и **Шок-Мины**. Узлы на расстоянии ≤2 клеток автоматически соединяются в единую сеть. Любая дуговая карта проходит по всей цепи и получает растущий бонус урона за каждый узел (`×1 → ×2 → ×3 → ×4+`).
2. **Кинетика и окружение:** отталкивайте врагов в стены и колонны (`💥 +3 Slam`), сбрасывайте их в **Пропасти** (мгновенная гибель обычных врагов), сталкивайте друг с другом или швыряйте прямо в ваши **Реле** ради взрыва по площади!
3. **Live-превью каждого хода:** при выборе карты и наведении на клетку арена заранее подсвечивает дуги, стрелки отталкивания, взрывы и точный летальный урон.

## Состав прототипа (30–60+ минут геймплея)

- **3 Сектора** с ветвящейся картой маршрутов (*Бои, Элиты, Мастерские, Чёрный Рынок, 8 Событий, 3 уникальных Босса*).
- **31 уникальная карта** (62 состояния с апгрейдами `+`) по 4 архетипам: *Дуга, Кинетика, Защита, Разгон*.
- **16 пассивных Модулей (Relics)**, включая 3 легендарных модуля Боссов.
- **16 типов врагов и боссов** с уникальным телеграфированием.
- **3 Пилота-Ядра** (`VOLT-01 «Искра»`, `TITAN-04 «Молот»`, `PULSE-09 «Квант»`), уровни сложности **Overdrive 0–3**, мета-прогрессия **Лаборатория Ядра** с автосохранением в `localStorage` и **Кодекс**.
- **Процедурный Web Audio синтезатор** (без внешних аудиофайлов) и переключение языка **RU / EN**.

> **Для проверяющих:** в разделе «Лаборатория Ядра» есть кнопка **«Режим ревьюера»**, мгновенно открывающая все 3 Ядра и уровни Overdrive 0–3 для быстрой оценки всего контента.

## Локальный запуск и тесты

```bash
npm install
npm run dev       # локальный сервер разработки
npm test          # автотесты движка (Vitest)
npm run build     # сборка production-версии в dist/
```

## Управление
- **ЛКМ** — выбор карты и клетки на арене (для карт без цели — двойной клик или клик по арене).
- **Клавиши `1–8`** — быстрый выбор карты в руке.
- **`E`** — завершить ход.
- **`Esc`** — отменить выбор карты.
